# NexaBank — Premium Digital Banking Dashboard

A polished digital banking dashboard built with **HTML, CSS and JavaScript**.

## Highlights
- Premium fintech dashboard UI
- Responsive desktop, tablet and mobile layouts
- Interactive balance visibility
- Virtual bank card design
- Cash-flow chart and spending visualization
- Savings goal progress
- Recent transactions and searchable statement
- Simulated money-transfer flow
- Saved recipients
- Card controls
- Profile/security settings
- Dark mode
- Mobile bottom navigation
- Toast notifications and modal interactions
- CSV statement export

## Tech
- HTML5
- CSS3
- Vanilla JavaScript
- Inline SVG for data visualization
- Browser APIs for the demo CSV export

## Run
Open `index.html` in a browser, or serve the folder with a simple local server.

## Important
This is a **frontend portfolio/learning project**. It does not connect to real bank accounts and does not move real money.

A production banking application would require secure authentication, authorization, backend services, encrypted data handling, database controls, audit logs, fraud detection, regulated payment/banking integrations, secure secrets management, monitoring, and compliance controls.
